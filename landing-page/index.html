Teknolojinin Zirvesi

Uygulamamızın kalbinde Google'ın en güçlü modellerinden Gemini 2.5 Flash yatıyor.

Akıllı Prompt Mühendisliği

Seçtiğiniz yılı (örn. "1950'ler") arka planda detaylı bir İngilizce sanat yönetmenliği komutuna dönüştürüyoruz.

Akıllı Hata Yönetimi

API yoğunluğunda bile deneyiminiz kesintiye uğramaz. Sistem otomatik olarak tekrar dener ve sizi bekletmez.


const generateImage = async (year) => {
  const prompt = createDetailedPrompt(year);
  
  // Google Gemini 2.5 Flash
  const response = await gemini.generate({
    model: "gemini-2.5-flash-image",
    prompt: prompt,
    style: "polaroid_vintage"
  });

  return response.image;
}
